# Nexus 枢纽 v0.1.17

## 配色重做：主题从「换强调色」变成「换整套调色板」

之前的八套主题共用一个深蓝底（`#0b0d12` / `#141821`），换主题只是换了一处高亮色——
设置页上八张色卡长得几乎一样，背景永远是同一块深蓝。这一版把每套主题做成**整套调色板**：
底色、卡面三级、分隔线、文字三级、强调色两级，共 12 个变量，外加 `color-scheme`。

## 为了让浅色主题不残，组件里写死的颜色全部改成 token

徽章、danger 按钮、输入框、flash、来宾徽章、提示条、表格 hover、设置页色卡预览、
以及六种背板的 `::before` 纹理，原本都是照着深色底写死的固定值（白光纹理、浅蓝字）。
现在一律由 `--accent / --accent-2 / --ok / --warn / --danger` 与 `--text` 用 `color-mix` 混出来：
深色底得到微光，浅色底得到微灰；`--shadow-glow` 也跟着强调色走，不再永远是蓝的。

改完 `:root` 之外没有硬编码十六进制色（`@media print` 的黑白除外），
样式表里 `rgb(255 255 255` 的残留是 0。
