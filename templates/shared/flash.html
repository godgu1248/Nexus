{#- 一次性提示消息（flash）。用法： {% import "shared/flash.html" as flash %} {% call flash::render(self.messages) %} 为什么是 macro 而不是 {% include %}：include 会共享父模板的上下文， 意味着每个引入它的页面都必须正好有一个叫 `messages` 的字段。macro 显式传参， 页面可以叫它任何名字，也可以在一次渲染里放两个 flash 区。 `kind` 只允许 success / error / info —— 它会被直接拼进 class， 所以值必须是代码里定的常量，绝不能来自用户输入。 -#} {% macro render(messages) %} {%- if !messages.is_empty() %}
{%- for message in messages %}

{{ message.text }}

{%- endfor %}
{%- endif %} {% endmacro %}
